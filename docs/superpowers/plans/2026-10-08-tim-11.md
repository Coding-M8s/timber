# TIM-11 implementation plan

**Goal:** Give the three development lanes a runnable CLI scaffold and shared contracts.
**Spec:** GitHub issue #1 and `docs/cli-contract.md`; no Git engine implementation.
**Architecture:** Commander parses arguments into injected asynchronous command handlers. Plain service interfaces carry repository context, resolution outcomes, configuration, worktrees, and cleanup evidence. Test doubles remain in tests.
**Execution:** One implementer, then one independent whole-branch reviewer.

## Constraints and review focus

Use TypeScript/Bun, Commander, Execa, Zod, smol-toml; exact dependency versions and committed lockfile. Linux x86_64 only. No Git mutations, destructive force option, runtime registry, editor/agent launch, or 0.2 integrations in the scaffold.
Review missing/excess arguments; help/error stream and exit behavior; inherited editor defaults; unknown/stale worktree and cleanup state; unexpected service calls in tests.
